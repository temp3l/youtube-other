## Editorial gates

- Narration files contain no headings or markup intended for TTS.
- All scripts are original English reconstructions; exact source-phrase overlap is mechanically checked and remains below the 12-word blocking threshold.
- No named external factual examples, statistics, quotations, testimonials, or claimed case-study results were introduced in this wave.
- A noisy transcript may contribute an idea, but it is never treated as authoritative wording. Cross-source support and semantic reconstruction are required.
- Before publication, normal factual/legal/editorial review still applies, especially if later revisions add named examples, research claims, statistics, or current platform advice.
