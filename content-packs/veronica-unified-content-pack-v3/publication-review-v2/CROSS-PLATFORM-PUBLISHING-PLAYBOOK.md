# Cross-Platform Publishing Playbook — v2

## Asset model

Each editorial episode has one canonical Long and two canonical Shorts. Platform variants should change **metadata, cover treatment, caption, CTA, and crop/edit details**, not create new story identities. Keep the same story IDs for analytics and provenance.

## Three-touch episode rollout

1. **Short A — discovery/tension.** Publish as the first touch on YouTube Shorts, TikTok, and Instagram Reels.
2. **Long — depth/framework.** Publish the canonical ~10-minute episode on YouTube and Vimeo after the problem has been seeded by Short A.
3. **Short B — diagnostic/payoff.** Publish as a standalone value piece after the Long; it may reference the full episode, but must still work without it.

## Platform role

| Platform | Primary role | Default asset | Editorial treatment |
|---|---|---|---|
| YouTube | Series home + depth + Shorts funnel | Long + both Shorts | Strong searchable title for Long; Shorts remain standalone and can point to playlist/full episode. |
| TikTok | Cold discovery and rapid idea testing | Shorts | Fast first visual beat, native caption, no dependence on a prior episode. |
| Instagram | Brand reinforcement + discovery | Shorts | Strong cover frame and concise caption; optimize for recognition and saves/shares rather than copying YouTube metadata. |
| Vimeo | Clean long-form library / portfolio | Long | Preserve canonical Long edit and metadata provenance; use as durable hosted version rather than the primary discovery engine. |

## Series rules

- Never make both Shorts trailers. At least one must deliver a complete diagnostic or framework.
- Do not publish conceptually adjacent episodes back-to-back when they use the same opening grammar or mechanism.
- Use the first six episodes as a learning tranche before changing the underlying scripts; optimize covers/titles/edit rhythm first.
- Track performance by story ID and platform variant so the same idea can be compared across channels.
- Selected TTS audio duration, not word count, becomes the final timing authority before release.
