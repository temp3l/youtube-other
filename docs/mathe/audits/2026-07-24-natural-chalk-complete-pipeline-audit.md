## Defect and migration

- **FACT:** `math-semantic-chalk.v4` applied one expanding rectangular
  `clipPath` to active text groups. This exposed vertical glyph slices.
- **FACT:** v5 replaces that path with grapheme-level outline-stroke
  accumulation, ordered path drawing for primitives, bounded deterministic
  variants, and fixed seeded grain. Complex nested text uses a token-local
  grain fallback; no line-wide rectangle is used.
- **FACT:** production burn-in captions are disabled by default. Separate
  caption artefacts remain authoritative.
- **FACT:** visual invalidation now follows dependency branches, so chalk
  changes preserve TTS and timing evidence.
- **FACT:** `math-narration-approved-v1` locks the recovered settings and
  regression tolerances.
