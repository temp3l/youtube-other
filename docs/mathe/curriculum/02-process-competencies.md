# Prozessbezogene Kompetenzen im Video

| Code | Kompetenz | Sichtbare Umsetzung |
|---|---|---|
| `ARG` | Argumentieren | Regel begründen, Behauptung prüfen oder Gegenbeispiel zeigen |
| `PROB` | Problemlösen | Problem strukturieren, Strategie wählen, Ergebnis prüfen |
| `MOD` | Modellieren | Realsituation vereinfachen, mathematisieren und zurückübersetzen |
| `REP` | Darstellen | zwischen Text, Tabelle, Term, Graph, Diagramm oder Figur wechseln |
| `OBJ` | Mit Objekten und Werkzeugen umgehen | Fachnotation, Algorithmen und Konstruktionen korrekt nutzen |
| `COM` | Kommunizieren | Fachbegriffe klar und altersgerecht verwenden |
| `MED` | Medien nutzen | digitale Darstellung sinnvoll einsetzen und kritisch prüfen |

Mindestens eine Prozesskompetenz muss in jeder Lesson-Spezifikation beobachtbar sein.
Ein bloßes Metadatenfeld reicht nicht.
