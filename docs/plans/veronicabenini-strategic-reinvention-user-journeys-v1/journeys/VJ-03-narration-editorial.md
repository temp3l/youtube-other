# VJ-03 — Produce Narration and Editorial Structure

## Primary actor
Creator / Editor

## Main flow
1. System derives an episode outline from the canonical episode revision and source manifest.
2. Narration is generated/adapted to the requested duration and genre voice.
3. Narration may reorganize source material for coherence while preserving intended meaning.
4. System separates spoken narration from on-screen text and production metadata.
5. Timing estimates are produced per narration segment.
6. Visual beats are aligned to narration segments.
7. Editor reviews narration with source links and change rationale.
8. Editor edits, approves, or rejects narration.
9. Approval freezes the narration revision for dependent stages.

## Rules
- TTS narration contains no editorial headings or markup unless explicitly intended to be spoken.
- Material narration edits invalidate timing-dependent artifacts.
- Minor metadata changes do not invalidate narration.
- Target duration is treated as a bounded editorial constraint rather than an exact character count.
