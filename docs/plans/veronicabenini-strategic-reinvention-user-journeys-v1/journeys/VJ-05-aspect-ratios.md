# VJ-05 — Produce 16:9 and 9:16 Editions

## Primary actor
Production Operator

## Main flow
1. Operator selects one or both target formats.
2. System uses the same canonical episode/narration revision.
3. Shared visual assets are reused when compositionally valid.
4. Layout-specific derivatives are created for 16:9 and 9:16.
5. Text is reflowed and resized independently per format.
6. Source slides may be redesigned/recomposed for vertical readability.
7. Safe-area and mobile readability checks run.
8. Each format is rendered independently.
9. Approval may be shared for common content while remaining format-specific for layout defects.

## Success outcome
Both formats remain semantically equivalent without requiring duplicate source/narration generation.
