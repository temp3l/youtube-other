# VJ-10 — Publish and Distribute

## Primary actor
Creator / Production Operator

## Main flow
1. User selects an approved rendered edition.
2. System derives title, description, tags, chapters, captions, thumbnail references, and target-language metadata.
3. Publishing preflight validates platform credentials, required metadata, visibility policy, and final approval state.
4. User can publish immediately, schedule, or export a delivery package.
5. Publishing records platform identifiers and immutable production revision references.
6. A localized edition can be published independently from the source-language edition.
7. Re-publishing does not silently replace another revision without explicit intent.

## Success outcome
Published content is traceable to its exact approved production revision.
