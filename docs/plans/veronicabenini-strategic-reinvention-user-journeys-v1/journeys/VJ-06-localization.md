# VJ-06 — Localize an Approved Episode

## Primary actor
Creator / Localization Reviewer

## Main flow
1. User selects an approved source-language episode revision and one or more target languages.
2. System creates language editions linked to the same canonical episode.
3. Narration is translated/adapted while preserving timing intent and genre voice.
4. Captions and metadata are translated.
5. Embedded/on-screen text is translated.
6. Language-independent images and source media are reused.
7. Visual assets are regenerated only when the language is embedded inseparably in the asset or the translated layout cannot be represented safely through composition.
8. TTS is generated with target-language provider/voice configuration.
9. Layouts are reflowed for target-language text expansion.
10. Localization reviewer sees only language-specific deltas plus relevant shared context.
11. Approved language edition becomes renderable/publishable independently.

## Success outcome
Localized editions avoid unnecessary image generation while remaining visually and editorially coherent.
