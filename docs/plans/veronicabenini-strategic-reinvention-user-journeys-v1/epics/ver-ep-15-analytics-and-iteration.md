# VER-EP-15 — Analytics and iteration

## VER-140 — Link analytics to production revision

**Priority:** P1  
**Actor:** Creator  
**Journeys:** VJ-13

As a creator, I want performance metrics linked to the exact published revision so that I know what creative produced the result.

### Acceptance criteria
- Platform metrics reference publication/revision IDs.
- Historical metrics are not reassigned when a new revision is created.
- Locale/format are dimensions.

## VER-141 — Compare formats and locales

**Priority:** P2  
**Actor:** Creator  
**Journeys:** VJ-13

As a creator, I want to compare 16:9/9:16 and localized editions so that I can decide where to invest production effort.

### Acceptance criteria
- Comparisons normalize/label platform and date context.
- Locale/format filters are explicit.
- No automatic causal claim is made from correlation alone.

## VER-142 — Fork from a successful pattern

**Priority:** P2  
**Actor:** Creator  
**Journeys:** VJ-13,VJ-01

As a creator, I want to create a new episode/revision from a high-performing pattern so that successful structures can be reused deliberately.

### Acceptance criteria
- Creates a new canonical resource/revision.
- Inherited settings/pattern references are explicit.
- Historical published artifact is unchanged.
