## Import boundary

The importer preserves raw source/hash provenance and produces typed
`SeriesImport`, 100 `EpisodeImport`, 400 `LocalizedScriptImport`, QA artifacts,
and continuity artifacts. The immutable import record includes import ID,
series ID, pack version, source root, manifest hash/hash-set revision, locales,
episode count, timestamp, and validation status.

Reject unsafe/absolute/traversal paths, symlinks, invalid hashes, missing or
unexpected required files, duplicate/missing IDs, unknown locales, malformed
metadata, manifest/episode disagreement, unresolved source lineage, or runtime
authority conflicts. Preserve raw Markdown for evidence but never make headings
the runtime domain model.

## Narrative and localization contracts

Each episode compiles a language-neutral `EpisodeBoundaryContract` containing
episode ID, outgoing state, audience and character knowledge, critical props,
cliffhanger semantic ID, and next-opening obligation. Hook projections retain
canonical intent while allowing idiomatic wording.

Protected terms:

- `DO_NOT_TRANSLATE`: character names, `7 MINUTES AHEAD`, `AHEAD`, `Return`,
  episode/receiver IDs, and V01–V18 identifiers.
- `FIXED_LOCALIZATION`: Signal (`Signal`, `Signal`, `Señal`, `Sinal`) and
  reviewed term families for receiver, observer, relay, anchor, annex, packet,
  countdown, and protocol.
- `CONTEXTUAL_LOCALIZATION`: ordinary location, action, and dialogue phrasing.

Future locales use canonical state, a canonical source script, and glossary to
produce a draft, deterministic QA, semantic parity QA, and an accepted revision.
They do not alter imported V5 revisions.

## Production profile and media reuse

`SevenMinutesAheadProductionProfile` owns series/pack identity, 9:16, supported
locales, default locale, speech profiles, runtime intent, visual policy, Signal
UI template, lip-sync policy, source-asset policy, editorial gate, timing policy,
and publication-target policy. These values are not generic constants.

- Shared canon/Beat/Scene/Shot semantic IDs and approved visual assets are the
  default across locales.
- Locale outputs own TTS, alignment, timing, subtitles, UI text, metadata, and
  final render/composition.
- A visual locale fork needs a recorded baked-text, semantic, cultural,
  legal/platform, or timing reason.
- V5 contains no visual registry. Seed future registry work from the eight
  named characters without inventing assets.
- E001–E003 should start with 5–7 strong source plates per episode and 8–12
  editorial cuts; this is a canary budget, not an engine constant.
- Use stable per-character/per-locale voice profiles and mixed narration/dialogue
  segmentation. Prefer reaction, listening, insert, phone, offscreen, and
  controlled-mouth shots over mandatory multilingual lip sync.
- Readable Signal/phone text is compositor-owned typed UI, never image-model text.
- Subtitle timing and line grouping derive independently from selected locale
  audio and platform-aware safe zones.

Shared visual cache keys exclude locale only when semantics contain no localized
content. TTS, subtitle, UI, metadata, timing, and render keys include locale.
Wording-only changes invalidate that locale downstream; canon beat changes may
invalidate all locales; character-reference changes invalidate affected shared
visuals. Shared visuals are costed once, while localized audio/render work is
costed by episode, locale, provider, asset type, and revision.

without bounded task scope and explicit side-effect authorization.

## Publication and analytics

`PublicationTargetProfile` maps series+locale+provider to an exact account,
metadata profile, schedule profile, and enabled flag. TikTok and YouTube metadata
are separate projections. Store schedule instants in UTC and never derive an
account or timezone from locale alone. AI-content disclosure follows media
provenance, not caption language.

Analytics observations retain canonical episode, locale, provider, account,
publication, render/metadata revision, and observation window. Cross-locale
comparisons annotate account baseline, audience, publish time, and experiment
context. They are observational unless controlled assignment supports causality
and never write canon directly.
