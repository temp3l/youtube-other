## Causal notes

HVP-P0-01 is a presentation defect, not narration loss. HVP-P0-02 through HVP-P0-04 are the actual P0 approval-safety defects. HVP-P0-05 is an upstream lineage defect: the content pack's complete conclusion is present upstream and in the current script, but no recorded operation proves why the persisted script has grown relative to its imported source. It must be investigated before treating runtime metadata as trustworthy.

No evidence shows truncation by floating-point arithmetic: beat ranges index text, while rounding affects only seconds. The exact 600 boundary does not cut a text range; it exposes the mistaken equal-duration model.
