## Profile release gate

No profile may publish based on aggregate score alone. Producer validity,
cross-artifact quality, approval, and publish authorization are distinct gates.
Hard correctness/policy failures are non-overridable. Provider-free deterministic
fixtures run by default; paid-provider and irreversible external checks are
separate opt-in jobs with explicit credentials and budgets.
