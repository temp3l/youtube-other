## Required characterization before migration

For each command row, capture exit code, stdout/stderr shape, help text, dry-run
write set, artifact paths/names, provider request identity, retry classification,
and state transitions. The canonical task and compatibility alias must pass the
same semantic assertions; only explicitly documented presentation differences
may remain. Commands that publish, upload, approve, reject, migrate, clean,
cancel, or import must additionally prove authorization and mutation boundaries.
