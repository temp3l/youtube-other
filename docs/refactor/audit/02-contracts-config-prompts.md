## Contract acceptance gates

- Domain schema changes require parse/round-trip/unknown-field tests and an
  explicit migration version; fixtures are classified before update.
- Prompt changes require compiler snapshot-by-hash (not broad text snapshots),
  response schema characterization, cache invalidation, and provider batch ID
  compatibility tests.
- Configuration changes require a precedence matrix including absent/empty
  values, dotenv/process conflicts, episode profiles, CLI overrides, secret
  redaction, and dry-run behavior.
- Provider changes require request fingerprint, retry/timeout/error mapping,
  usage accounting, debug redaction, and offline fake characterization before
  any paid or external verification.
