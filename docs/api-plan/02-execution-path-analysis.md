## Entry-point safety rule

- **Recommended:** controllers, workers, and schedulers call typed application handlers only.
- **Recommended:** a temporary subprocess adapter may be used for a characterized operator-only command with fixed argv mapping, scrubbed environment, bounded output/time, and no public caller-controlled syntax.
- **Recommended:** no HTTP route may select a local root, filename, executable, provider base URL, prompt, or task implementation.

## State and naming findings

- **Verified:** canonical episode paths use `canonical/`, `locales/`, `shared/`, `visuals/`, and `state/`, while resolvers and readers retain fallbacks such as `languages/`, root/output scenes, and older generated-image paths (`packages/shared/src/episode-filesystem.ts` and tests; `packages/metadata/src/youtube-metadata.ts:findEpisodeScenesFile`).
- **Verified:** runtime and authored audio/script paths can differ, and Short/full markers are inferred from path names in legacy publishing.
- **Inferred:** public identity derived from filenames would preserve ambiguity and permit traversal. Public IDs and explicit locale/variant fields must replace it.

## Logging and audit finding

Operational Pino/provider/process telemetry is present. No current entry path consistently records authenticated principal, workspace authorization decision, immutable approval/publication audit, and causation chain. Audit is a target-state application responsibility.
