# End-to-end journeys

## JNY-001 — First Episode
**Participating stories:** US-055, US-004, US-016–019, US-006, US-005, US-026–028, US-058. **Persona:** tenant admin then producer. **Starting state:** tenant exists; no episode. **Terminal state:** approved, publish-ready revision. **Journey:** configure entitlement/capabilities and defaults; create typed brief; admit pinned provider-free workflow; inspect validation/artifacts; submit and decide exact challenge. **Major transitions:** tenant ready → brief revision → run → validated evidence → review decision → publish-ready. **Cross-service/API boundaries:** BFF/API, workflow worker, artifact/validation/approval stores. **Security boundaries:** session/tenant authorization; secrets server-side. **Failure/recovery:** unsupported capability, validation failure, stale approval. **Audit points:** setup, admission, decision.

## JNY-002 — Normal Production
**Participating stories:** US-006–011, US-025–028, US-031–033. **Persona:** producer/reviewer. **Starting state:** approved brief. **Terminal state:** published or publish-ready where execution disabled. **Journey:** brief → plan/generate → validate → submit/review/approve → render → pre-publish gate → publish. **Major transitions:** revision pinned; workflow stages; evidence validated; approval bound; render approved; intent/effect. **Cross-service/API boundaries:** API/workers, providers, artifact store, YouTube adapter. **Security boundaries:** worker credentials and publication permission. **Failure/recovery:** US-007/035; stale approval US-028. **Audit points:** run, review, intent/effect.

## JNY-003 — Failure Recovery
**Participating stories:** US-001, US-007, US-011, US-025, US-061–062. **Persona:** producer. **Starting state:** partial failed run. **Terminal state:** resumed completion, safe abandonment, or escalated blocker. **Journey:** queue → timeline/error → preserved artifacts → retryability/invalidation review → resume selective stage → revalidate. **Major transitions:** running → failed → retrying/resumed → terminal. **Boundaries:** UI/API durable workflow/worker. **Security:** sanitized diagnostics. **Failure/recovery:** nonretryable/provider ambiguity stops effect. **Audit:** retry/abandon/correlation.

## JNY-004 — Selective Regeneration
**Participating stories:** US-008–011, US-017–018, US-026–028, US-061–062. **Persona:** producer/reviewer. **Starting state:** approved/produced revision. **Terminal state:** target regenerated, target validated, review valid or renewed. **Journey:** select one asset → preview downstream invalidations → issue scoped regeneration → validate affected output → mark/bind stale approval → rereview if required. **Transitions:** evidence hash changes; dependent gates reevaluate. **Boundaries:** dependency graph/workflow/artifact/approval. **Security:** authorization and provider policy. **Recovery:** unsafe scope refusal. **Audit:** target/invalidation/run/decision.

## JNY-005 — Localization
**Participating stories:** US-012–015, US-013, US-019, US-026–028, US-031–033. **Persona:** producer/reviewer. **Starting state:** approved source revision. **Terminal state:** approved localized derivative, publish-ready/published. **Journey:** locale admission → derivative creation → reuse source visuals → localize narration/text/TTS/captions/metadata → validate/compare → review → publish. **Transitions:** source linked to derivative; locale evidence independently approved. **Boundaries:** capability/translation/voice/render/publication. **Security:** entitlement/voice consent. **Recovery:** partial derivative retry. **Audit:** reuse/localization/decision.

## JNY-006 — Bulk Production
**Participating stories:** US-001, US-020–025, US-026, US-060–062. **Persona:** producer. **Starting state:** selected eligible briefs. **Terminal state:** per-item completed, blocked, or safely failed result. **Journey:** filter → usage/capability/quota preflight → queue batch → monitor → isolate/retry failures → submit eligible review packs → aggregate results. **Transitions:** batch → child admissions/runs. **Boundaries:** dashboard/API/batch scheduler/workers. **Security:** per-item authorization. **Recovery:** partial failure is never hidden. **Audit:** selection/preflight/item actions.

## JNY-007 — Reviewer
**Participating stories:** US-002, US-008–009, US-026–029, US-062. **Persona:** reviewer. **Starting state:** active challenge. **Terminal state:** immutable approve/reject/request-changes decision or safe stale refusal. **Journey:** queue → open challenge → inspect evidence/validation/comparison → decide → audit/history. **Transitions:** active challenge → consumed decision; artifact change → stale. **Boundaries:** review API/artifact delivery/audit. **Security:** reviewer role and tenant scope. **Recovery:** expired/competing decision rejected. **Audit:** decision bindings/rationale.

## JNY-008 — API Consumer
**Participating stories:** US-041–047, US-004–005, US-026–028. **Persona:** developer/service principal. **Starting state:** scoped credential. **Terminal state:** approved artifact/result retrieved. **Journey:** create credential → create project/episode → start pinned run with idempotency key → poll or verify webhook → coordinate review → fetch approved results. **Transitions:** command/replay/run/review. **Boundaries:** OpenAPI/API, webhook endpoint, customer review process. **Security:** scopes/signatures/tenant isolation. **Recovery:** typed problem, retry key, webhook replay dedupe. **Audit:** service principal/correlation.

## JNY-009 — Publishing Recovery
**Participating stories:** US-031–036, US-061–062. **Persona:** producer. **Starting state:** publish-ready immutable intent. **Terminal state:** published or reconciled safe failure. **Journey:** execute upload → transient/ambiguous fault → inspect marker/effect → retry publication only or reconcile → retrieve post-publish state. **Transitions:** intent → executing → reconciliation_required/retry → published. **Boundaries:** API worker, YouTube adapter, reconciliation. **Security:** channel lease/OAuth server-side. **Recovery:** no regeneration, no blind duplicate upload. **Audit:** effect/attempt/result.

## JNY-010 — Provider-Free Acceptance
**Participating stories:** US-004–006, US-008, US-011, US-026–028, US-042–043, US-058. **Persona:** producer or API consumer. **Starting state:** local/CI provider-free tenant. **Terminal state:** deterministic approved evidence set and audit trail. **Journey:** capability check → typed brief → provider-free run → validation/artifact inspection → hash-bound review decision → result retrieval. **Transitions:** no external provider/publish effect. **Boundaries:** BFF/API, provider-free worker, durable repository. **Security:** no browser/provider secrets. **Recovery:** injected deterministic failure/resume. **Audit:** complete command/run/decision chain.
