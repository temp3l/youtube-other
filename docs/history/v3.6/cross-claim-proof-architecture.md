# V3.6 cross-claim proof architecture

`CrossClaimProofV36` is a bounded, upstream proof record for the one approved Phase 2.9 Black Death gap. It is neither an `ExplanatoryRelation` nor a candidate.

The contract permits exactly two ordered, distinct claims from one episode. Its sole pattern joins an uncertain wage-demand condition to an attempted wage-restriction response through an explicit inventory-approved typed dependency between resolved canonical bindings. This preserves each premise’s modality; it does not assert a completed historical relation.

Proximity, narration order, scene, paragraph, labels, and claim-pair enumeration are never evidence. Exact source spans/hashes and all claim, structured-proposition, atomic-grounding, and participant-binding lineage remain on each premise. `proofId` hashes only directed semantic content; the separate evidence fingerprint hashes IDs and source lineage.

The deterministic validator is authoritative and fails closed for cardinality, same-claim, cross-episode, unsupported shape, modality, unresolved binding, join, direction, duplicate, and source errors. Candidate admission is deferred because the accepted relation contract cannot preserve this uncertain/attempted modality tuple.
