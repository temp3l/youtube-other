# Horror Stories Episodes 140–189 — YouTube Rewrites

This package contains:

- `rewritten_episodes/` — 50 rewritten Markdown scripts for episodes 140–189.
- `reports/analysis-and-fixes-report.md` — source analysis, repeated-template findings, and what was fixed.
- `reports/episode-rewrite-summary.csv` — compact per-episode summary.
- `000-index-rewritten-episodes-140-189.md` — index of all rewritten scripts.

## Production target

- Narration: restrained adult male documentary-horror tone.
- Pace: 175–185 wpm.
- Approximate duration: 5.7–6.8 minutes per episode with restrained pauses.
- Visual rhythm: new visual beat every 6–10 seconds.
- Content: supernatural horror, implication over graphic gore.
