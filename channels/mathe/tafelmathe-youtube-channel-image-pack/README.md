# TafelMathe YouTube Channel Image Pack

This pack contains the generated visual identity assets for the German mathematics channel **TafelMathe**.

## Ready-to-upload assets

| File | Purpose | Dimensions |
|---|---|---:|
| `tafelmathe-channel-logo-800x800.png` | Channel profile image | 800 × 800 |
| `tafelmathe-channel-banner-main-2560x1440.png` | Primary channel banner | 2560 × 1440 |
| `tafelmathe-channel-banner-alternative-2560x1440.png` | Alternative banner | 2560 × 1440 |
| `tafelmathe-video-thumbnail-template-1280x720.png` | Long-form video thumbnail template | 1280 × 720 |
| `tafelmathe-video-end-screen-template-1920x1080.png` | End-screen background | 1920 × 1080 |
| `tafelmathe-video-watermark-transparent-150x150.png` | Transparent video watermark | 150 × 150 |

## Folder structure

- `ready-to-upload/`: correctly named and resized YouTube exports.
- `masters/`: original full-resolution generated PNG files.
- `preview/`: contact sheet showing all assets.
- `manifest.json`: machine-readable asset metadata for pipeline integration.

## Recommended usage

Use the **main banner** initially. Keep the alternative banner for seasonal tests or A/B comparisons. Replace `THEMA` and `Klasse 7` in the thumbnail template for each lesson. Verify the channel banner in YouTube's device preview before publishing because television, desktop, tablet and mobile crops differ.
